# v0.5实测摘要（公开版）

本文只概述静态对照结果，不包含论文原文、提示全文、作者批注、生成输出或账号运行日志。详细原始记录保存在私人本地目录，不随仓库发布。

## 试验

从第九轮论文旧稿中选取8组、13段有明显表达问题的材料，比较普通提示“审查并润色”和v0.5。每组每种条件生成一次，共16次；模型为gpt-5.6-luna，推理强度low，使用同一原文及必要上下文。选段理由没有给生成模型；每次在独立临时会话运行。

案例为定向问题回归，不是随机样本。评阅为执行助手的非盲复核，未做作者盲评或人工接受度调查。结果不具统计显著性，也不构成长论文端到端验证。

## 观察

- 背景段中，v0.5将“连续证据链、共同接口”改为具体说明规划任务与逐栋资源、测算和部署分析之间的衔接。这是可辨认的局部改善。
- 多数其他问题段，v0.5仍保留重复否定、清单式说明或机械流程用语，整体收益有限。
- 个别输出改变了表达范围，例如把“单一主体可组织”改为“权利主体相对单一”。二者不能视作等义。
- 审查说明有时把措辞调整称为解决逻辑问题，修改说明本身也需核实。

## 结论

本轮没有证据证明v0.5整体优于普通提示。示例段落仅展示一次输出，不代表作者认可或普遍效果。Skill仍需人工核对正文的论述作用、术语、证据和章节位置。

早期版本的测试使用不同案例与规则，不能合并成单一胜率。公开材料不对模型优劣作超出当前样本的推断。
